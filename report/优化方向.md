# 霞客行整体优化六方向（2026-11-12 夜跑拟定）

> 六个维度各立一项，每项含做什么/为什么/工作量/教学价值。本次夜跑按「教学价值优先、离线可行不依赖外部 API key、复用现有资产」三标准选 3 项实施（标 ✅），其余留档待后续迭代。

## 一、体验打磨 —— 浏览器离线语音朗读原文 ✅【本次实施】

- **做什么**：原文阅读器每段注入"朗读"按钮，用浏览器自带 `speechSynthesis`（Web Speech API）朗读段落，支持停止；纯前端、离线可用（走系统语音）。
- **为什么**：古籍对初中生阅读门槛高，听读结合显著降低进入门槛；朗读时无需逐字盯屏，适合晨读场景。
- **工作量**：小（一个朗读控制模块 + 阅读器按钮注入，约 60 行，零新依赖）。
- **教学价值**：高——把"读游记"变成"听游记"，直接服务原文阅读器这一核心页。

## 二、内容扩容 —— 游记冷门篇章扩充

- **做什么**：从《徐霞客游记》再精选 2-3 篇（如《游嵩山日记》《游太华山日记》）按现有考据流程（抓底本→清洗→引文核验→配题）扩为第 8/9 篇章。
- **为什么**：现 7 篇覆盖手册规定 7 类地貌已完整，扩容增加广度但边际教学价值递减；且每篇都要走完整考据闭环（引文逐字回查底本），一晚无法保证考据纪律。
- **工作量**：大（每篇约半天起，含考据）。
- **教学价值**：中——广度增加，深度不变；**本次不实施**（考据红线：宁缺毋滥）。

## 三、练习与游戏化 —— 章节综合测验卷 + 每日一题 ✅【本次实施】

- **做什么**：① 新增"章节综合测验"路由：把本篇章各点位题库混合抽卷（上限 10 题、按日期种子可复现），交卷走既有 AI 批改与错题入本；② 首页新增"每日一题"卡：按日期从全题库轮换一题，即答即判。
- **为什么**：点位练习是单点记忆，章节卷考"跨点位综合理解"，正是研学与刷题的分界；每日一题制造回访钩子。
- **工作量**：中（组卷/判分/错题全复用现有件，新增约 200 行 + 断言）。
- **教学价值**：高——从"学过"到"测过"，教师端天然能看到班级卷面。

## 四、地图升级 —— 万里遐征总路线图 ✅【本次实施】

- **做什么**：新增"遐征全图"页：一张 Leaflet 地图聚齐 7 篇章 25 点位，按游历顺序连线成"万里遐征"总路线，点位按地貌着色，点击直达点位页。
- **为什么**：现有地图按篇章分页，学生缺一张"徐霞客到底走了多远"的全局图——这正是《游记》研学的题眼。
- **工作量**：中（复用 map.js 底图与墨韵滤镜，新增聚合连线约 100 行 + 断言）。
- **教学价值**：高——空间全局观 + 成就感（走完的点会亮）。

## 五、数据与后端 —— 教师端云端同步

- **做什么**：学习档案从 localStorage 升级为可选云端同步（教师看板跨机器汇总）。
- **为什么**：当前单机档案，换机房数据即失；但项目定位是**零依赖离线研学站**（file:// 可开），上后端破坏这一立身之本。
- **工作量**：大（需服务器与账号体系）。
- **教学价值**：中——**本次不实施**（与离线定位冲突）。

## 六、AI 能力深化 —— 助教追问链与考点追答

- **做什么**：助教对话升级为可追问的多轮链（当前单轮问答），批改后可对错题发起"考点追答"。
- **为什么**：多轮对话教学体验更好；但真实追问链依赖 API key（离线引擎做确定性多轮会显著膨胀规则库），违背"离线可行"标准。
- **工作量**：中偏大（离线规则库翻倍或引入 API 依赖）。
- **教学价值**：中——**本次不实施**（留待有 API 条件的课堂场景）。
