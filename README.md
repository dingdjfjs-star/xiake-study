# 霞客行 · 《徐霞客游记》研学站

跟着徐霞客读山河：**古籍原文 × 七类地貌 × 打卡答题 × 成就图鉴** 的跨学科研学应用。
纸墨手账风、零框架零构建、离线优先、file:// 直开亦可。

> 对应《「霞客行」ZCode 落地全配置手册》的完整落地实现——手册中的"页面设计器/工作流/AI组件/数据模型"
> 在这里以真实代码实现：学生端 5 页 + 教师端 4 页 + 7 节点工作流 + 4 组内置提示词 + 4 张基础数据表。

## 快速开始

- 双击 `启动.bat`（或 `node server.js`）→ http://localhost:8946 （监听 0.0.0.0，会打印局域网地址给手机）
- 也可直接双击 `index.html`（file:// 直开；底图瓦片需联网，其余全离线可用）

## 玩法（学生端 5 页）

| 页面 | 路由 | 说明 |
|---|---|---|
| 研学首页 | `#/` | 7 篇章卡片，按地貌/难度/关键词筛选，任务卡、进度条 |
| 篇章路线页 | `#/chapter/:id` | 左侧点位列表 + 右侧 Leaflet 地图：游历路线连线、按地貌配色编号、卫星/地形/**墨韵古图**三底图切换 |
| 点位研学详情页 | `#/point/:pid` | 手绘风地貌示意图（本地 SVG 引擎）+ 原文/注释/白话/知识点 + **AI 跨学科助教** + 打卡 |
| 智能答题页 | `#/quiz/:pid` | 每点位 3 题（选择/填空/材料简答），本地确定性批改或 AI 批改，错题自动入本 |
| 个人图鉴与成就页 | `#/collection` | 7 类地貌插画图鉴（打卡点亮）+ 18 枚成就徽章墙 + 错题本（答对自动移出）+ 语录卡 |
| 原文阅读器 | `#/reader/:id` | **12 篇《徐霞客游记》底本全文**（国学梦全文库，约 3.8 万字）：日次朱砂标题分章、分篇页签、读毕计入成就 |
| 霞客其人 | `#/about` | 小传、三大历史贡献、行迹年表（约年如实标注）、语录墙（已核底本朱砂框 / 通行传述灰框） |

内容规模：**7 篇章 · 25 点位 · 75 题 · 18 成就 · 12 篇底本全文（约3.8万字）**，覆盖手册规定的全部 7 类地貌
（花岗岩峰林-黄山 / 喀斯特-桂林七星岩 / 丹霞-武夷九曲溪 / 火山-雁荡·天台 / 流水-石梁·三叠泉 / 湖泊湿地-滇池草海 / 山地峡谷-石门涧·梁皇山）。

## 教师端 4 页（`#/teacher/...`）

- **学情看板**：完成率/正确率/易错知识点分布（按地貌类）/学生排名。含本机真实档案 + **种子化模拟班级（演示数据，明确标注）**，接入真实班级后可替换。
- **任务管理**：新建班级任务（篇章+截止时间）一键发布，学生端首页同步出现任务卡。
- **题库管理**：内置 75 题总览 + 追加/删除校本题（存本机，答题时自动生效）。
- **优秀作业展示**：采集学生材料简答题作答，标记"优秀"上墙。

## AI 双模式（手册 4 组提示词全部内置）

- **离线引擎（默认）**：助教=按点位考据卡做检索式组答；批改=选择题/填空精确判分、简答按评分关键词命中率给分——**零积分、零网络、结果确定性可测**。
- **真实 API（可选）**：设置页填入 OpenAI 兼容接口（默认智谱 `glm-4-flash`）+ Key 即切换；调用失败自动回退离线并在回复中注明。
- 4 组提示词（古籍实体识别 / 插画生成 / 研学助教 / 出题批改）可在 **设置页查看与一键复制**。

## 手册工作流 → 实现对照

| 手册节点 | 实现 |
|---|---|
| 1 任务启动 | 学生端任务卡 / 教师端发布（`#/`） |
| 2 古籍地理实体解析 | **人工考据固化**为 `js/data-points.js`（25 点位古今地名/坐标/地貌/原文/注释），比单次 AI 解析更可靠；NER 提示词内置备用于其他平台 |
| 3 路线渲染 | `js/map.js`（Leaflet 连线 + 地貌配色 + 三底图） |
| 4 内容批量生成 | 知识点卡人工编研 + `js/paint.js` 本地生成手绘风剖面示意（离线"AI 插画"） |
| 5 学习与打卡 | `#/point/:pid` 打卡 → 自动进入答题 |
| 6 智能批改与学情 | `js/ai.js`（离线双引擎 / API 模式）+ 错题本 + 看板 |
| 7 归档与成就 | localStorage 档案 + `js/achievements.js`（13 枚判定）+ 消息通知（toast） |

## 考据纪律（重要）

- `verified:true` 的 22 条引文已逐字对照底本（国学梦全文库，tools/source/ 存档，test.js §13 回归把关）；3 条非徐记来源维持 segSrc 注明；出处篇名一律如实标注。
- 8 个点位的引文出自经典诗文名句（孙绰赋/朱熹棹歌/李白诗/王正功诗/大观楼长联等），均以 `segSrc` 明确注明，不冒充徐记原文。
- "薄海内外无如徽之黄山"等流传甚广但考据存疑的句子，在篇首即标注"待核"——**这本身就是教学素材**。
- 原文底本抓取与逐条核对记录见 [report/考据说明.md](report/考据说明.md)；凌晨补跑脚本见 `tools/`。

## 扩展

- 加篇章/点位：改 `data-chapters.js` / `data-points.js`，配好题库 `data-questions.js` 后**必跑 test**（会替你抓结构错误与泄露）。
- 引文核正：拿到底本后核对 `seg`，逐条把 `verified` 改 `true`，并在 `report/考据说明.md` 留痕。
- 加地貌插画：在 `paint.js` 的 `SCENES` 注册新场景函数。
- 部署：纯静态，GitHub Pages 可直接托管（`.nojekyll` 即可）；或复用工作区 `github-pages-deploy` 技能。
